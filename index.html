Guide de Modification (Pour les élèves)

Vous voulez personnaliser ce jeu ? Voici comment faire :

  1. Ouvrez ce fichier avec un éditeur de texte (comme le Bloc-notes ou VS Code).
  2. Cherchez la variable banqueQuestions dans le script.
  3. Vous pouvez ajouter ou modifier les questions et les réponses. Respectez bien la syntaxe {q:"Question", a:"réponse"}.
  4. Pour changer les codes secrets, modifiez la liste codes.
  5. Enregistrez et rafraîchissez la page !
